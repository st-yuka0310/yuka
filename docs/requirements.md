# 自炊貯金（仮）要件メモ

## コンセプト

ズボラでも続く「自炊したらいくら浮いたか」がわかるアプリ。
将来は家計簿アプリに育てるが、まずは自炊の節約トラッカーを核にする。

**一番大事な体験**
ごはんを作ったら「作った！」を1タップ → 「今月 ◯円浮いた ＝ ラーメン◯杯分」が見える。

## 前提

- 利用端末: iPhone
- 家計簿アプリは未使用（これ1本で始める）
- 開発: Claude がほぼ実装、本人はレビュー・試用
- 達成感で一番効くもの: **換算**と**貯められた金額**

## 節約額の考え方

```
節約額 = 外食したら払っていた額 − 自炊にかかった額
```

- 朝・昼・夜ごとに基準額を持つ（初期値）
  | 食事 | 外食なら | 自炊コスト | 浮いた額 |
  |---|---|---|---|
  | 朝 | 450円 | 150円 | 300円 |
  | 昼 | 900円 | 300円 | 600円 |
  | 夜 | 1,300円 | 450円 | 850円 |
- 記録時は基準額で自動計算。必要なときだけ金額を手直しできる
- 基準額は設定で変更できる

### 食材費で確定する（月単位）

買い出しは2週間に1回＋細かい買い足しが多いので、1回ごとの材料費ではなく**月の合計**で考える。

```
その月の浮いたお金 = その月の外食相当額の合計 − その月の食材費の合計
1食の実際の単価   = 食材費の合計 ÷ 自炊した回数
```

- 食材を買ったら金額を入れて「追加」するだけ（何回でも足せる）
- **月の途中**は目安の材料費で計算する（まとめ買い直後にマイナスになって、やる気が下がるのを防ぐ）
  - 実際の1食単価と「今の時点で確定した場合の額」は参考として表示する
- **月が終わったら**食材費の合計で確定し、これまでの合計や目標の貯金びんに反映する
  - 食材費を1回も入れなかった月は目安の金額のまま
- 設定画面で「先月の実際の単価」に目安の材料費を合わせられる（朝・昼・夜の比率は保つ）

## MVP（v0.1）の機能

1. **作った！ボタン**: 朝/昼/夜は時刻から自動選択。1タップで記録。取り消しできる
2. **貯まった額**: 今月の節約額、これまでの合計
3. **換算**: ラーメン・コンビニ弁当・カフェラテ・映画などに置き換えて表示
4. **目標（貯金箱）**: 「欲しいもの」と金額を決めると、瓶に貯まる見た目で進み具合を表示
5. **連続記録**: 何日続けて自炊しているか
6. **食材費**: 買った金額を足していき、月末に合計で確定
7. **履歴**: 月ごと・日ごとの一覧（月の確定額と1食単価つき）、記録の削除
8. **設定**: 基準額、目標、データのリセット

## あとで検討（v0.2 以降）

- 実際に貯金口座へ移した額の記録（「浮いた額」と「本当に貯めた額」を分ける）
- 換算アイテムを自分で追加
- 月ごとのグラフ、月末のふりかえり
- 家計簿機能（外食・食費・その他の支出）
- 通知（夕方に「今日は作った？」）
- ホーム画面ウィジェット、ネイティブアプリ化（Swift）

## 技術方針

- まずは **Web アプリ（PWA）**。iPhone の Safari で開き「ホーム画面に追加」でアプリのように使う
  - Mac や Apple Developer 登録なしで始められる
  - 使い続けたくなったら Swift でネイティブ化を検討
- 1ファイル構成（`src/app.html`）、ライブラリなし
- データは端末内に保存（ブラウザのストレージ）
