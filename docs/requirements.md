# 自炊貯金（仮）要件メモ

## コンセプト

ズボラでも続く「自炊したらいくら浮いたか」がわかるアプリ。
将来は家計簿アプリに育てるが、まずは自炊の節約トラッカーを核にする。

**一番大事な体験**
ごはんを作ったら「作った！」を1タップ → 「今月 ◯円浮いた ＝ ラーメン◯杯分」が見える。

## 前提

- 利用端末: iPhone
- 家計簿アプリは未使用（これ1本で始める）
- 開発: Claude がほぼ実装、本人はレビュー・試用
- 雰囲気: 女子大生が楽しく使える、かわいいパステル系。アイコンのおにぎりキャラが応援してくれる。iPhone がダークモードでもピンクの見た目のまま
- 達成感で一番効くもの: **換算**と**貯められた金額**

## 節約額の考え方

```
節約額 = 外食したら払っていた額 − 自炊にかかった額
```

- 朝・昼・夜ごとに基準額を持つ（初期値）
  | 食事 | 外食なら | 自炊コスト | 浮いた額 |
  |---|---|---|---|
  | 朝 | 450円 | 150円 | 300円 |
  | 昼 | 900円 | 300円 | 600円 |
  | 夜 | 1,300円 | 450円 | 850円 |
- 記録時は基準額で自動計算。必要なときだけ金額を手直しできる
- 基準額は設定で変更できる

### 食材費で確定する（月単位）

買い出しは2週間に1回＋細かい買い足しが多いので、1回ごとの材料費ではなく**月の合計**で実際の1食単価を出す。
**一度貯まったお金は減らさない**（月末に確定して金額が下がると、やる気が下がるため）。

```
1食の実際の単価   = 食材費の合計 ÷ 自炊した回数
```

- 食材を買ったら金額を入れて「追加」するだけ（何回でも足せる）
- **月の途中**は目安の材料費で計算する（まとめ買い直後にマイナスになって、やる気が下がるのを防ぐ）
  - 実際の1食単価と「今の時点で確定した場合の額」は参考として表示する
- **月が終わったら**実際の1食単価がわかる。貯まった額や目標は書きかえない
- 設定画面で「先月の実際の単価」に目安の材料費を合わせられる（朝・昼・夜の比率は保つ）

## MVP（v0.1）の機能

1. **作った！ボタン**: 朝/昼/夜は時刻から自動選択。1タップで記録。取り消しできる。「きのう」や日付を選んで、過去の日の分も記録できる（食材費も同じ）
2. **貯まった額**: 今月の節約額、これまでの合計
3. **換算**: 自分の身の回りのもの（フラペチーノ、リップ、推しのライブなど）に置き換えて表示。設定で自由に追加・削除できる
4. **目標（貯金箱）**: 「欲しいもの」と金額を決めると、豚の貯金箱にコインが貯まる見た目で進み具合を表示
   - 目標はいくつでも持てて、全部同時に進む。それぞれ**追加した日からの節約額**で貯まる
   - 豚に入れる目標はタップで入れかえ。達成したら「買った！」で「かなえた目標」に移る（ほかの目標は減らない）
5. **連続記録**: 何日続けて自炊しているか
6. **食材費**: 買った金額を足していき、月末に合計で確定
7. **応援キャラ**: おにぎりのキャラが吹き出しで話しかける。記録すると喜んで跳ねる。タップすると応援してくれる
8. **履歴**: 月ごと・日ごとの一覧（月の確定額と1食単価つき）、記録の削除
9. **設定**: 基準額、目標、データのリセット

## あとで検討（v0.2 以降）

## 技術方針

- まずは **Web アプリ（PWA）**。iPhone の Safari で開き「ホーム画面に追加」でアプリのように使う
  - Mac や Apple Developer 登録なしで始められる
  - 使い続けたくなったら Swift でネイティブ化を検討
- 1ファイル構成（`src/app.html`）、ライブラリなし
- データは端末内に保存（ブラウザのストレージ）
